# Project 4: Unsupervised Image Clustering and Visualization

This project applies unsupervised machine learning techniques to the MNIST handwritten digit dataset.

I used **K-Means clustering** to group similar handwritten images and the **Elbow Method** to determine an appropriate number of clusters. I also analyzed the cluster centroids and tested the trained model on unseen images.

**PCA** and **t-SNE** were used to reduce the dimensionality of the image data and visualize the discovered clusters in two-dimensional space.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook / Google Colab
